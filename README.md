# Visão Geral

O projeto consiste na criação de uma Landing Page Estática para uma empresa fictícia NutriBox. Criado como atividade prática da primeira unidade da cadeira de Desenvolvimento Web I

Curso: Tecnólogo em Análise e Desenvolvimento de Sistemas
Instituto Federal de Ciência e Tecnologia de Pernambuco (Campus Recife)

---

### Requisitos do Projeto
- Seguir as especificações de design indicadas pelo professor
- Sem responsividade inicialmente
- Só é permitido estilização à base de **FlexBox**
- Obrigatório **escrita semântica** do HTML
- Seguir **boas práticas** de estrutura e estilo
- Organização de arquivos por categorias

---

### Tecnologias

- **HTML5:** Estrutura da página
- **CSS3:** Criação do estilo
- **Live Server:** Desenvolver com visualização em tempo real

---

### Como visualizar

- Clonar o projeto no seu ambiente de desenvolvimento
- Abrir o arquivo index.html no navegador
